# 카드 사진

`p01.webp` ~ `p140.webp`는 친구 사진 카드 이미지 140장(`카드이미지/01_주먹부터.png`, `카드이미지/091_손바닥번개.png` 등)을 400px webp로 줄인 것이다. 원본 사진은 넣지 않는다.
파일 번호가 `js/cards.js`의 카드 ID와 같다. 예: `p01` = 주먹부터.

사진을 바꾸려면 같은 이름으로 덮어쓴다. 정사각형 이미지를 권장하고, 카드에서는 가운데 위쪽(세로 30% 지점)을 기준으로 잘린다.
다른 카드의 사진을 같이 쓰려면 `js/cards.js`에서 카드에 `photo: 'p12'`처럼 지정한다.
