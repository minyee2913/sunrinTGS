# 허리펴라

친구 사진으로 싸우는 턴제 덱빌딩 배틀로얄 (3~6인, 브라우저).
GitHub Pages로 화면을 배포하고, Firebase Realtime Database로 상태를 주고받는다. 판정은 호스트 브라우저가 한다.

## 바로 테스트 (Firebase 없이)

`js/config.js`의 `apiKey`가 비어 있으면 **로컬 테스트 모드**로 실행된다. 같은 브라우저의 탭끼리만 연결된다.

```bash
python -m http.server 8000
```

`http://localhost:8000/?p=1`, `?p=2`, `?p=3`을 각각 새 탭으로 열고 서로 다른 닉네임으로 참가한다.
ES 모듈을 쓰기 때문에 파일을 더블클릭해서 열면 동작하지 않는다. 꼭 로컬 서버로 연다.

## 친구들과 플레이 (Firebase 연결)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만든다 (Spark 무료 요금제).
2. **Authentication → 로그인 방법 → 익명**을 사용 설정한다.
3. **Realtime Database**를 만든다. 위치는 아무 곳이나 괜찮다.
4. Realtime Database의 **규칙** 탭에 `database.rules.json` 내용을 붙여넣고 게시한다.
5. **프로젝트 설정 → 내 앱 → 웹 앱 추가**에서 나온 설정값을 `js/config.js`의 `FIREBASE`에 넣는다. `databaseURL`도 꼭 넣는다.
6. GitHub 저장소에 올리고 **Settings → Pages**에서 브랜치를 배포한다.
7. Firebase **Authentication → 설정 → 승인된 도메인**에 `<아이디>.github.io`를 추가한다.

Firebase 설정값이 프런트엔드 코드에 들어가는 것은 정상이다. 데이터 접근은 보안 규칙이 제한한다.
Firebase 연결 상태에서도 주소 뒤에 `?local`을 붙이면 로컬 테스트 모드로 열 수 있다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `js/config.js` | Firebase 설정, 체력·에너지·제한 시간 등 수치 |
| `js/cards.js` | 카드 24종 정의와 시작 덱 |
| `js/engine.js` | 전투 규칙 (호스트에서만 실행) |
| `js/host.js` | 요청을 순서대로 판정하고 결과를 기록 |
| `js/net.js` | Firebase / 로컬 테스트 통신 |
| `js/app.js`, `js/view.js` | 화면 |
| `database.rules.json` | Realtime Database 보안 규칙 |
| `img/cards/` | 카드 사진 (`img/cards/README.md` 참고) |

## 데이터 구조 (`hp/` 아래)

| 경로 | 내용 | 읽기 | 쓰기 |
| --- | --- | --- | --- |
| `meta` | 상태(lobby/playing), 게임 ID, 호스트 | 모두 | 호스트 (호스트가 끊기면 다른 참가자가 이어받기) |
| `lobby/<uid>` | 닉네임, 입장 시각, 접속 탭 | 모두 | 본인, 호스트 |
| `pub` | 공개 전투 상태 (체력·방어도·로그 등) | 모두 | 호스트 |
| `priv/<uid>` | 손패, 내 덱, 카드 선택 후보 | 본인, 호스트 | 호스트 |
| `req/<uid>` | 행동 요청 | 본인, 호스트 | 본인, 호스트 |
| `hs` | 덱 순서, 숨겨진 반응, 난수 상태 | 호스트 | 호스트 |

## 구현하면서 정한 것들

기획서에서 “구현 시 정한다”로 남겨둔 항목은 이렇게 정했다. 수치는 대부분 `js/config.js`에서 바꿀 수 있다.

- 손패 상한 10장. 넘치는 드로우는 멈추고, 넘치는 방해 카드는 버린 더미로 간다.
- 0비용 반복 방지: `폰 보기`·`아아 수혈`은 한 턴 1번, `손가락 튕기기`는 한 턴 2번.
- 호스트 연결이 끊기면 20초를 기다린다. 그 안에 호스트가 새로고침해서 돌아오면 게임이 그대로 이어진다. 돌아오지 않으면 게임을 끝내고, 가장 먼저 들어온 접속자가 새 호스트가 된다.
- 같은 브라우저에서 탭을 여러 개 열면 마지막 탭만 조작할 수 있다. 다른 탭에는 “여기서 계속하기”가 뜬다.
- 반응 카드는 사용 로그에도 “반응 카드 설치”로만 남는다. 무슨 반응인지는 발동할 때 공개된다.
- “왜 나만”의 기준은 “지난 내 턴 이후 나를 공격한 상대”다. 방어도나 무효에 막혔어도 공격자로 센다.
- 제거 단계에서 덱은 5장 아래로 줄일 수 없다.
- 방해 카드 `현타`: 1에너지로 쓰면 덱에서 사라진다. 턴이 끝날 때 손에 남아 있으면 자신이 피해 2를 받는다.
